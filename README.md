# Coffeeroasters Website

Welcome to the **Coffeeroasters Website** repository! This project is a beautifully designed coffee e-commerce website that allows users to explore, subscribe, and purchase high-quality coffee from various roasters.

## 🚀 Features
- Modern and responsive design
- Subscription-based coffee delivery service
- Interactive UI with smooth animations

## 🛠️ Technologies Used
- HTML, CSS, SCSS
-  Bootstrap 5, (Frontend)

## 📦 Installation

To get started with the project, follow these steps:

1. **Clone the repository:**
   ```sh
   git clone https://github.com/yourusername/coffeeroasters-website.git
   cd coffeeroasters-website
   ```

2. **Install dependencies:**
   ```sh
   npm install
   ```

3. **Start the development server:**
   ```sh
   npm start
   ```

The website will be available at `http://localhost:3000/`.
